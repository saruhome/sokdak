# 티콘파이 생성 캐릭터의 SokDak 이용 범위 사전검토

> **법률 검토 초안 — 변호사의 법률 자문이 아닙니다.** 아래 내용은 제공된 티콘파이 약관 발췌와 공개된 서비스 안내를 바탕으로 한 운영·권리 점검 메모입니다. 외부 베타 배포, 스토어 제출, 유료 광고 또는 상업 출시 전에 지식재산권 전문가의 검토 또는 티콘파이의 서면 확인을 받아야 합니다.

## 결론

티콘파이 공식 FAQ는 “**본인이 사용할 권리를 가진 이미지와 컨셉으로 만든 결과물은 상업적 활용 가능성이 있습니다**”라고 안내합니다.[1] 따라서 호랭이·짹이가 SokDak 운영자가 권리를 보유한 원본 이미지와 컨셉만을 바탕으로 생성된 결과물이라면, 해당 FAQ는 **조건부 상업 활용을 뒷받침하는 공개 근거**가 됩니다. FAQ는 이모티콘의 외부 플랫폼 심사 제출도 사용자의 선택으로 안내합니다.[1]

다만 “가능성이 있습니다”라는 표현은 무조건적 허가나 권리 보증보다 좁습니다. 또한 FAQ와 Use Notice는 생성물의 이용·배포·상업적 활용에 대한 책임을 이용자에게 두고, 플랫폼 심사·권리 침해·상표 기준은 사용자가 직접 확인해야 한다고 명시합니다.[1] 그러므로 앱·웹·스토어·광고에서 사용할 계약상 권리가 자동으로 확정되었다고 보기는 어렵고, **수정·crop·공개 저장소 배포·권리 귀속·독점성·출처 표기·기간·지역 제한**은 여전히 확인되지 않았습니다.

## 확인된 사항과 확인되지 않은 사항

| 항목 | 현재 근거 | SokDak에 대한 판단 |
| --- | --- | --- |

| 생성물 이용 책임 | FAQ와 공식 사이트 고지는 생성물의 이용·배포·상업적 활용 책임을 사용자에게 둔다.[1] | 상업 활용의 조건부 가능성을 안내하지만, 분쟁이 생기면 SokDak이 직접 대응해야 할 수 있다. |
| 외부 플랫폼 제출 | FAQ는 이모티콘 심사 제출을 사용자의 선택으로 안내하되 심사 통과·권리 문제 없음을 보장하지 않는다고 정한다.[1] | 외부 제출을 금지하지는 않지만, 앱스토어·플레이스토어 기준과 상표·저작권 기준은 SokDak이 직접 확인해야 한다. |
| 앨범 공개 | 공개를 선택한 결과물은 티콘파이 앨범·소개 영역에 노출될 수 있다고 정한다. | 공개 상태와 권리 귀속은 별개다. 공개 전환 기록이나 공개 앨범 URL은 권리 증빙이 아니다. |
| 상업 이용 허가 | 공식 FAQ는 권리를 보유한 이미지·컨셉으로 만든 결과물의 상업적 활용 가능성을 명시한다.[1] | **조건부 근거 확보.** 원본 입력물의 권리를 증명할 수 있는 경우, 비공개 베타의 앱 내 사용 근거가 된다. 다만 외부 배포·마케팅 범위는 별도 확인이 바람직하다. |
| 수정·crop·2차적 이용 | 앱 UI에 맞춘 투명화, 크기 변경, 배경 제거, 포즈별 파생 사용의 허가 문구를 확인하지 못했다. | **미확인.** 앱 에셋 편집과 재배포에 필요한 권리인지 확인해야 한다. |
| 권리 귀속·독점성 | 결과물의 저작권 또는 계약상 사용권이 누구에게 귀속되는지, 다른 이용자와 유사 결과물이 생성될 수 있는지 확인하지 못했다. | **미확인.** 브랜드 핵심 마스코트로 독점성·등록 가능성을 전제하면 안 된다. |

## SokDak별 위험 평가

호랭이·짹이는 앱의 빈 상태, 저장·제안 성공 피드백, 웹 소개 등 브랜드 식별 영역에 사용되고 있다. 이 경우 단순 개인 감상용 이용보다 **앱 내 배포, 상업적 브랜딩, 마케팅 소재 재이용**에 가까워지므로, 서비스 약관에 명시적 사용권이 없다면 위험이 커집니다. 특히 현재 SokDak 저장소가 공개 상태라면 해당 파일을 저장소에 넣는 행위 자체도 제3자에게 복제·접근 가능한 형태의 배포가 될 수 있습니다.

또한 생성형 AI 결과물은 입력물·프롬프트·후편집에 대한 사람의 창작적 기여, 기존 저작물과의 실질적 유사성, 서비스 제공자의 계약상 라이선스를 분리해서 점검해야 합니다. 한국저작권위원회도 생성형 인공지능 결과물의 침해 판단 요소와 이용자 유의사항을 별도 안내서로 제공하고 있으며, 인간의 창작적 기여가 있는 AI 활용 저작물의 등록 실무도 별도로 다룹니다.[2] [3]

> SokDak 모바일 앱과 웹의 브랜드 마스코트로 티콘파이 생성 캐릭터를 사용하려 합니다. 아래 사용 범위가 현재 계정·이용 플랜에서 허용되는지 서면으로 확인 부탁드립니다.
>

> 5. 티콘파이 자체 캐릭터·기본 에셋·스타일을 포함한 경우의 별도 제한 여부
> 6. 동일하거나 유사한 결과물이 다른 이용자에게 제공될 수 있는지와 독점성 부여 여부

## 현재 운영 결정 (FAQ 반영)

호랭이·짹이가 SokDak 운영자가 권리를 보유한 원본 이미지·컨셉에서 생성된 것임을 보관 자료로 입증할 수 있다면, 현재 공식 FAQ를 근거로 **비공개 베타의 앱 내 장식·빈 상태·성공 피드백 용도**는 조건부로 유지할 수 있습니다. 이 판단은 티콘파이의 FAQ가 상업적 활용 가능성을 공개 안내한다는 점에 근거하되, 어떠한 독점성이나 무제한 재배포권을 전제하지 않습니다.[1]

아래 네 가지가 서면으로 확인되기 전에는 호랭이·짹이를 **SokDak의 독점 브랜드 자산 또는 권리 등록 대상**으로 표현하지 않고, 유료 광고·대규모 공개 캠페인·상업 머천다이즈·제3자 라이선싱에는 사용하지 않습니다.

1. 상업적 이용과 앱·웹 재배포의 허용 여부
2. 수정·파생 사용과 출처 표기 조건
3. 티콘파이 또는 제3자의 권리가 결과물에 남는지
4. 생성한 이용자에게 부여되는 사용 범위·기간·지역 및 독점성

비공개 베타에서도 FAQ 스크린샷, URL, 확인일, 계정·플랜, 입력 원본과 생성 기록을 함께 보관해야 합니다. 스토어 공개·유료 광고·공개 GitHub 배포는 위 범위 확인을 거친 뒤로 잡는 것이 가장 안전합니다.
