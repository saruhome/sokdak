# Release Candidate QA 체크리스트

**대상:** private-beta 이후 각 release candidate 빌드 (EAS build, Expo Go 제외)
**플랫폼 표기:** AND = Android 실기기, IOS = iOS 실기기, BOTH = 양쪽 모두 수행
**기록 방법:** 각 행의 "실제 결과 / 증적 / Pass·Fail"을 채운다. 증적은 스크린샷·화면녹화 파일 경로 또는 이슈 링크.
**공통 사전 조건:** 별도 명시가 없으면 "네트워크 연결됨, 테스트 계정 사용(운영 사용자 계정 금지)".

## 출시 중단 기준 (하나라도 해당하면 release 중단)

- 타 사용자 데이터 노출 또는 수정 가능
- service role key / access·refresh token / signed URL이 UI·로그·에러 화면에 노출
- 계정 삭제가 타 사용자 데이터를 삭제
- private 이미지(profile-avatars)가 비인가 사용자에게 노출
- 로그인 불가 또는 유효 세션 복원 불가
- 핵심 화면(홈/사전/커뮤니티/마이페이지) 무한 로딩
- Android/iOS 중 한 플랫폼에서 핵심 인증 흐름(가입/로그인/로그아웃) 불가

## 시나리오

각 ID의 형식: 사전 조건 → 실행 단계 → 기대 결과. "실제 결과 / 증적 / P·F"는 실행 시 기입.
