# SokDak UGC 모더레이션 운영 절차

**문서 버전:** 1.0
**적용 대상:** 게시글, 댓글, 답글, 게시 이미지, 프로필 이미지, 신조어 제안, 지원 문의
**운영 원칙:** 신고는 운영자가 Supabase `reports` 테이블의 `status = 'open'` 항목부터 처리한다. 운영자는 일반 사용자 계정이 아니라 Supabase 대시보드의 제한된 운영 권한 또는 신뢰된 서버 경로로만 `reports`·`posts`·`comments`의 모더레이션 상태를 변경한다.

## 1. 역할과 최소 응답 목표

| 역할 | 책임 | 목표 응답 시간 |
|---|---|---:|
| 1차 검토자 | 신고 분류, 콘텐츠 임시 숨김 필요성 판단, 상태 변경 기록 | 일반 신고 24시간 이내 |
| 2차 검토자 | 영구 삭제·반복 위반·이의제기 검토 | 72시간 이내 |
| 릴리스/보안 담당 | 대규모 악용, 개인정보 유출, 아동 안전, 계정 침해 대응 | 인지 즉시 착수 |
| 고객지원 담당 | 처리 결과·추가 자료 요청·이의제기 안내 | 상태 변경 후 24시간 이내 |

출시 전 운영 주체는 위 역할마다 **실명 담당자와 대체 담당자, 연락 수단, 부재 시 인계 방법**을 내부 운영 문서에 기입해야 한다. 역할명만으로는 실제 대응 체계가 완성되지 않는다.

## 2. 신고 분류 기준

| 심각도 | 예시 | 즉시 조치 |
|---|---|---|
| 긴급 | 아동 성착취, 신체 위협, 자해·폭력의 구체적 조장, 개인정보·계정정보 노출, 불법 거래 | 콘텐츠를 즉시 `hidden` 또는 `removed`로 변경하고 증적·처리 시각을 기록한다. 필요한 경우 현지 법령과 내부 정책에 따른 관계 기관 협조 절차를 시작한다. |
| 높음 | 혐오·차별·괴롭힘, 성적 착취·사기·피싱, 반복 스팸, 저작권·초상권 침해 | 검토 중 숨김을 우선 적용하고 24시간 내 최종 조치한다. |
| 일반 | 욕설, 주제 이탈, 경미한 분쟁, 중복 게시물 | 24시간 내 검토하고 경고·숨김·삭제 또는 기각을 기록한다. |

## 3. 처리 절차

신고를 열면 대상 유형, 신고 사유, 작성자, 신고자, 게시 시각, 관련 댓글·이미지·이전 신고 이력을 확인한다. `reports.status`는 `open → in_review → actioned` 또는 `dismissed` 순서로 유지한다. 조치가 필요한 게시글·댓글은 각각 `moderation_status`를 `hidden` 또는 `removed`로 변경하고 `moderated_at`, `moderation_reason`, 보고서의 `reviewed_at`, `reviewed_by`, `resolution_note`를 함께 기록한다.

대상 콘텐츠를 숨기면 일반 사용자에게는 더 이상 노출되지 않지만, 원작성자는 자신의 콘텐츠 상태를 확인할 수 있다. 공개적 비난이나 신고자 정보 공개는 금지한다. 신고자가 보복·협박 위험에 처할 수 있으면 신원·메시지의 접근 범위를 운영 담당자에게만 제한한다.

## 4. 차단·제재·이의제기

사용자 차단은 이용자가 직접 수행할 수 있는 안전 기능이며, 운영 제재와 별개다. 반복 또는 중대한 위반에 대한 계정 제한은 서비스 운영 주체가 적용 법령·약관·증거 보존 의무를 검토한 뒤 신뢰된 관리 경로에서 실행한다. 모든 제재에는 대상, 근거, 범위, 시작 시각, 검토자, 재검토 예정 시각을 기록한다.

이의제기 요청은 고객지원 티켓으로 받고 2차 검토자가 원 조치자와 독립적으로 판단한다. 법적 보존 의무나 안전상 긴급 사유가 없는 경우, 계정 삭제 요청과 UGC 삭제 요청은 정해진 보존·파기 정책에 따라 처리한다.

## 5. 운영 점검

매일 신규 `open` 신고 수, 24시간 초과 미처리 건수, 긴급 신고 수, 숨김·삭제 비율을 확인한다. 매주 반복 신고 계정, 자주 발생하는 사유, 오탐·누락 사례를 검토해 금칙어·이미지 검사·운영정책을 개선한다. 월 1회는 신고 생성→숨김→고객지원→이의제기까지 모의훈련을 실시한다.

## 참고 자료

Apple은 UGC 앱에 부적절 콘텐츠 필터, 신고·신속 대응, 사용자 차단, 공개 연락처를 요구한다.[1] Google Play는 UGC 생성 전 정책 수락, 금지 행동 정의, 지속적 모더레이션, 신고·차단 및 적절한 조치를 요구한다.[2]
