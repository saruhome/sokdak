04 / CORE USER JOURNEYS

안전성과 신뢰를 닫는 네 가지 여정

기능이 보이는지보다, 계정 경계·복구·삭제가 실제 기기에서 일관되는지를 먼저 확인합니다.

저장 단어

CJ-04
행동저장·해제를 반복하고 앱을 재시작한 뒤 저장 목록을 다시 엽니다.
통과상태와 순서가 일관되고, 다른 테스트 계정의 목록이 보이지 않습니다.
계정 격리 실패 = P0

커뮤니티 참여

CJ-05
행동정책 확인 뒤 게시글·댓글·좋아요·신고·차단을 전용 계정으로 수행합니다.
통과데이터는 해당 계정에만 반영되고 신고·차단 정보는 제3자에게 보이지 않습니다.
신고·차단 노출 = P0

네트워크 복구

CJ-06
행동검색·저장·목록 로딩 중 오프라인 전환과 Wi-Fi/LTE 전환을 반복합니다.
통과앱 종료, 무한 로딩, 중복 카드, 저장 상태 역전 없이 재시도할 수 있습니다.
우회 불가 복구 실패 = P1

회원탈퇴

CJ-07
행동전용 테스트 계정에서 탈퇴를 확정하고 재로그인·앱 재시작·사진 접근을 확인합니다.
통과세션과 private 프로필 사진 접근이 정리되고, 삭제 계정의 정보가 남지 않습니다.
삭제 뒤 개인 정보 잔존 = P0

커뮤니티 정책 동의는 검토된 버전별 정책 전문·언어별 공개 URL·해시가 배포된 뒤에만 통과 판정으로 처리합니다.
