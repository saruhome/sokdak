# SokDak 제품 핵심 원칙과 기능 위계

**기준일:** 2026-08-22

## 제품의 한 문장

> **SokDak은 여러 플랫폼에 흩어진 한국 신조어를 한곳에 모아, 외국인 사용자가 뜻·뉘앙스·실제 사용법을 믿고 확인하게 돕는 다국어 실전 표현 사전이다.**

이 문장이 모든 제품 판단의 출발점이다. SokDak은 범용 한국어 문법 앱, 범용 번역기, 범용 AI 문장 생성기, 영상 강의 플랫폼으로 확장하지 않는다. 문장 코치·영상·저장·커뮤니티는 각각 신조어를 **발견하고, 이해하고, 안전하게 쓰고, 다시 꺼내는 과정**을 더 잘하게 만드는 보조 경험이다.

## 기능 위계

| 위계 | 사용자 과업 | 핵심 기능 | 보조 기능의 연결 |
| --- | --- | --- | --- |
| **핵심 1 — 발견** | 방금 들은 신조어를 찾는다 | 한국어·로마자·영어·일본어·베트남어·스페인어·독일어·음성 검색, 카테고리, 최신 신조어 | 공유 카드·오늘의 신조어가 검색으로 유입시킨다 |
| **핵심 2 — 이해** | 뜻과 뉘앙스를 신뢰한다 | 짧은 뜻, 발음, 유래, 다국어 설명, 실제 예문, 민감도 | TTS와 썸네일·짧은 영상이 이해를 보강한다 |
| **핵심 3 — 판단** | 내가 이 표현을 써도 되는지 안다 | 친구·직장·온라인·공적 자리의 사용 가능/주의/피해야 함, 대체 표현 | 문장 나침반이 선택한 신조어를 안전한 문장으로 이어 준다 |
| **핵심 4 — 반복** | 다시 찾아 실제로 쓴다 | 저장, 즐겨찾기 카테고리, TTS, 개인 복습 | 문장·영상 기반 복습이 기억을 강화한다 |
| **핵심 5 — 연결** | 다른 학습자 경험을 참고한다 | 로그인 기반 커뮤니티, 정책 동의, 신고·차단 | 저장한 신조어 관련 질문·답변을 복습에 연결한다 |

## 기능별 제품 역할

| 기능 | SokDak에서의 역할 | 하지 않을 일 |
| --- | --- | --- |
| 신조어 사전 | 제품의 중심. 무료로 검색·기본 뜻·예문을 제공한다 | 단어 표제어와 안전 경고를 결제 뒤에 숨기지 않는다 |
| 문장 나침반 | 찾은 신조어를 실제 상대·상황에 맞춰 써 보는 보조 도구 | 사전 검색을 대체하는 독립 범용 회화 코스가 되지 않는다 |
| 영상 | 실제 톤·장면·대체 표현의 증거 | 긴 문법 강의나 권리 불명확한 제3자 콘텐츠를 유료화하지 않는다 |
| 저장·복습 | 개인 신조어 사전을 만든다 | 너무 이른 한도로 첫 가치 경험을 막지 않는다 |
| 커뮤니티 | 실제 사용 경험을 교환하는 신뢰·유지 장치 | 읽기·안전 기능을 유료 장벽으로 만들지 않는다 |

## 유료 가치의 원칙

무료 사용자는 어떤 신조어인지, 무슨 뜻인지, 기본적으로 조심해야 하는지까지 알 수 있어야 한다. 유료 사용자는 자신이 저장한 신조어를 더 깊이 자기 것으로 만든다. 따라서 SokDak Context는 무제한 저장·TTS·카테고리, 관계별 심화 사용 가이드, 대체 표현, 저장한 신조어 기반 문장 경로, 권리가 확보된 장면 영상, 개인 복습 큐를 제공한다.

> **무료는 ‘알게 함’, 유료는 ‘자연스럽고 안전하게 계속 쓰게 함’이다.**

## UX 판단 질문

새 기능·화면·영상·마케팅 문구를 만들기 전에 다음 질문을 순서대로 확인한다.

1. 이 선택이 사용자가 흩어진 신조어를 더 빨리 찾고 이해하게 하는가?
2. 이 선택이 실제 사용의 관계·톤·위험을 더 명확히 하는가?
3. 이 선택이 사전의 신뢰를 높이는가, 아니면 범용 언어 앱처럼 보이게 하는가?
4. 이 선택이 무료 사용자의 첫 신조어 이해를 막지 않는가?
5. 유료 가치라면 ‘더 많이 본다’가 아니라 ‘더 자연스럽고 안전하게 쓴다’는 결과로 설명되는가?

하나라도 “아니오”이면 SokDak의 핵심을 희석할 가능성이 있으므로 우선순위를 낮춘다.
