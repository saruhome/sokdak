# SokDak 디자인 평가 관찰 기록

## 홈 화면 웹 렌더링 — 2026-08-16

- 모바일 폭으로 중앙에 렌더링되며, 외부 여백은 어두운 톤이고 앱 본문은 따뜻한 오프화이트 배경이다.
- 상단 다크 헤더에는 SokDak 워드마크, 검색, 알림 아이콘이 있지만 헤더 높이가 낮고 워드마크·아이콘 모두 작아 첫 시선에서 정보 밀도가 높다.
- 로컬 콘텐츠가 비어 있는 상태에서 히어로 캐러셀과 새 신조어 카드가 보이지 않아, 실제 첫 화면은 ‘오늘의 실전 표현’ 카드와 빈 커뮤니티 중심으로 매우 짧게 끝난다.
- 첫 번째 유효 콘텐츠인 실전 표현은 큰 카드, 섹션 제목, 보조 문구, 상황 배지, 한국어·영어 텍스트, 프리미엄 티저를 함께 포함해 한 카드에 시각 계층이 다소 많이 겹친다.
- ‘새로운 신조어’와 ‘커뮤니티’는 제목·보조문구·더보기 링크만 보이고 콘텐츠가 없어, 스크롤 여백이 많으며 홈의 핵심 가치가 약하게 인지된다.
- 5개의 하단 탭은 아이콘만 제공하고 활성 상태는 작은 어두운 pill로 구분된다. 작은 해상도에서는 아이콘의 의미와 선택 상태가 빠르게 읽히지 않는다.

## 카테고리 화면 웹 렌더링 — 2026-08-16

카테고리 화면은 검색, 정렬, 2열 카드 그리드로 구조가 단순해 목적은 명확하다. 다만 추천 카드가 데이터 로드·캐시 상태에 따라 보이지 않을 수 있고, 첫 화면에서 작은 검색 필드와 정렬 행, 10개 이상의 이미지 카드가 경쟁해 추천 행동의 우선순위가 사라진다. 카드 안에는 마이크 아이콘, 즐겨찾기 별, 큰 카테고리 제목이 모두 있어 150×104 영역에서 정보 밀도가 높다. 특히 일부 긴 한국어 라벨은 2행으로 커지고, 배경 이미지 위의 큰 검정 타이포그래피와 반투명 오버레이가 이미지별로 대비가 일정하지 않다. 모든 카드에 동일한 마이크 아이콘을 반복하는 것은 카테고리 구분의 신호보다 시각적 잡음으로 보인다.

## 커뮤니티 진입·로그인 화면 웹 렌더링 — 2026-08-16

비로그인 상태에서 하단 커뮤니티 탭을 누르면 커뮤니티의 화제글·게시판·읽기 콘텐츠를 보여주지 않고 즉시 로그인 화면으로 전환된다. 이는 초기 사용자에게 커뮤니티의 가치를 보여 주는 탐색 경로를 끊는다. 로그인 화면은 넉넉한 여백, 워드마크, 두 마스코트, 단일 ‘이메일로 로그인’ CTA로 브랜드 인상은 분명하다. 반면 이메일 필드와 비밀번호 입력이 바로 보이지 않아 CTA를 한 번 더 눌러야 하는지, 어떤 인증 방법인지가 약하게 전달된다. 상단 좌측 뒤로가기 아이콘은 단독 기호여서 작은 화면에서 행동 의미와 터치 영역을 확인하기 어렵다.
