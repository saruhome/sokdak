# SokDak Android·iOS 다국어 UI 및 오류 복구 QA 체크리스트

**대상 빌드:** Expo Go가 아닌 development build 또는 EAS Android/iOS release build

**대상 Android 기기:** Pixel 1종과 Samsung Galaxy 1종 이상

**대상 iOS 기기:** 화면이 작은 iPhone 1종과 노치 또는 Dynamic Island가 있는 iPhone 1종 이상

**대상 언어:** 한국어(ko), 영어(en), 일본어(ja), 베트남어(vi), 스페인어(es)

## 공통 준비

각 언어에서 앱을 완전히 재시작한 뒤 **마이페이지 → 언어 설정**으로 해당 언어를 선택합니다. Android 시스템 글자 크기는 기본값·130%·200%에서, iOS는 기본 텍스트 크기와 Larger Text에서 각각 점검합니다. 네트워크가 연결된 상태에서 사전과 카테고리 화면을 처음 열어 데이터 로딩 완료도 확인합니다.

iOS에서는 상단 노치/Dynamic Island, 하단 홈 인디케이터에서 Safe Area가 적용되어 헤더·CTA·검색창이 가려지지 않는지 확인합니다. Android에서는 제스처 내비게이션과 3버튼 내비게이션을 모두 확인합니다.

## 카테고리 검색

| 확인 항목 | 기대 결과 | 완료 |
|---|---|---|
| 검색창 placeholder | ko `카테고리 검색`, en `Search categories`, ja `カテゴリーを検索`, vi `Tìm danh mục`, es `Buscar categorías`가 표시된다. | ☐ |
| 존재하지 않는 검색어 제출 | 언어별로 완성된 결과 없음 문장이 표시된다. 예: en `No results found for “test”.`, ja `「test」の検索結果はありません。` | ☐ |
| 검색어 지우기 | 입력값이 있을 때 `X` 버튼이 나타나며, 탭하면 입력과 결과 없음 상태가 사라지고 최근 검색/추천 카테고리 화면으로 돌아간다. | ☐ |
| 버튼 폭·줄바꿈 | 베트남어·스페인어 `X` 접근성 문구와 일본어 긴 문자열이 아이콘·입력창·헤더와 겹치거나 잘리지 않는다. | ☐ |
| 키보드 | 검색 키를 누르면 검색이 제출되고, `X`를 탭해도 키보드·포커스 상태가 비정상적으로 닫히지 않는다. | ☐ |
| Safe Area | iPhone 노치·홈 인디케이터, Android 상태바·내비게이션 바에서 검색창과 헤더가 가려지지 않는다. | ☐ |

## 사전 검색과 번역 일치 근거

| 확인 항목 | 기대 결과 | 완료 |
|---|---|---|
| VI 의미 검색 | 악센트가 있는 베트남어 및 악센트를 생략한 입력 모두 결과를 찾고, `Khớp với nghĩa dịch: 🇻🇳 VI`가 표시된다. | ☐ |
| ES 의미 검색 | 악센트가 있는 스페인어 및 악센트를 생략한 입력 모두 결과를 찾고, `Coincide con la traducción: 🇪🇸 ES`가 표시된다. | ☐ |
| 사전 검색 지우기 | 5개 언어에서 입력값이 있을 때 지우기 버튼이 나타나고, 탭하면 전체 목록으로 복귀한다. | ☐ |
| 정렬 명확성 | en `Korean consonant (ㄱㄴㄷ)`, vi `Theo phụ âm đầu (ㄱㄴㄷ)`가 화면 폭에서 잘리지 않는다. | ☐ |
| 한국어 음성 검색 | 어떤 UI 언어에서도 음성 검색 안내가 ‘한국어 단어’ 인식 기능임을 명확히 알리고, 권한 허용·거부·설정 이동이 정상 동작한다. | ☐ |

## 오류 복구 UI

오류 경계는 렌더 단계 오류를 복구 UI로 전환하는 공통 Android·iOS 기능입니다. 네트워크·RPC·이벤트 오류는 별도 사용자 안내와 재시도 경로를 사용하므로, 두 흐름을 모두 점검합니다. 오류 재현은 내부 QA용 오류 재현 경로 또는 테스트 전용 빌드에서만 수행하고, 일반 베타 사용자 빌드에 의도적 오류를 남기지 않습니다.

| 확인 항목 | 기대 결과 | 완료 |
|---|---|---|
| 저장 언어 후 첫 오류 | 앱을 완전히 종료한 뒤 ko/en/ja/vi/es 중 하나를 저장하고, 첫 화면 렌더 오류를 재현하면 해당 저장 언어의 제목·본문·CTA가 즉시 표시된다. | ☐ |
| 문구와 CTA | 제목·본문·재시도 버튼이 현재 UI 언어로 표시되며, 베트남어·스페인어 제목의 두 줄 표시도 겹침·잘림 없이 읽힌다. | ☐ |
| 재시도 성공 | `다시 시도`/`Try again` 등 언어별 CTA를 누르면 정상 화면으로 돌아간다. | ☐ |
| 반복 오류 | 재시도 후에도 오류가 계속될 때 앱이 빈 화면·무한 로딩·강제 종료 상태가 되지 않고 복구 UI를 다시 표시한다. | ☐ |
| 네트워크 실패 | 비행기 모드 또는 불안정한 네트워크에서 RPC/데이터 요청 실패가 오류 경계를 우회하더라도 현지화된 사용자 안내와 재시도 경로를 제공한다. | ☐ |
| 큰 글자 | Android 100%·130%·200%, iOS 기본·Larger Text에서 제목·본문·CTA가 모두 보이고 CTA의 탭 영역이 유지된다. | ☐ |

## 화면 읽기 접근성

Android에서는 TalkBack, iOS에서는 VoiceOver를 켠 뒤 검색창, 지우기 버튼, 음성 검색 버튼, 카테고리 결과 행, 오류 복구 제목·재시도 버튼 순서로 포커스를 이동합니다. 각 요소가 현재 UI 언어로 읽히고, `X` 버튼이 단순히 ‘아이콘’이 아니라 ‘검색어 지우기’에 해당하는 동작으로 읽혀야 합니다. 오류 복구 화면이 열리면 오류 안내가 먼저 읽히고 재시도 버튼에 도달할 수 있어야 합니다.

| 언어 | 카테고리 지우기 버튼이 읽어야 하는 라벨 | 오류 복구 CTA 예시 | 완료 |
|---|---|---|---|
| ko | 검색어 지우기 | 다시 시도 | ☐ |
| en | Clear category search | Try again | ☐ |
| ja | 検索語を消去 | もう一度試す | ☐ |
| vi | Xóa nội dung tìm kiếm danh mục | Thử lại | ☐ |
| es | Limpiar búsqueda de categorías | Reintentar | ☐ |

## 완료 기준 및 기록

각 기기·언어 조합에서 텍스트 잘림, 줄바꿈 문제, 잘못된 언어 표시, Safe Area 침범, TalkBack/VoiceOver 누락 라벨이 없어야 합니다. 문제가 발견되면 **플랫폼, 기기 모델, OS 버전, 앱 빌드 번호, UI 언어, 화면 경로, 재현 단계, 스크린샷 또는 화면 녹화**를 함께 기록합니다. 언어별 번역의 어감은 베타 참여 원어민의 피드백도 별도로 수집합니다.
