# SokDak 문장 코치 UX·수익화 전략

**작성:** Manus AI

**기준일:** 2026-08-22

**제품 재정의:** SokDak은 흩어진 한국 신조어를 한데 모아 뜻·뉘앙스·실제 사용법을 안내하는 사전이며, 문장 코치는 사용자가 **찾은 신조어를 실제 상황에서 자연스럽고 안전하게 써 보도록 돕는 보조 경험**이다.

## 핵심 결론

SokDak이 다른 언어 앱과 달라질 수 있는 첫 번째 지점은 각 플랫폼에 흩어진 신조어를 빠르게 찾아, 다국어 설명과 실제 사용 맥락으로 신뢰 있게 안내하는 데 있다. 문장 코치는 그 신조어를 찾은 뒤 초급 학습자가 **말할 목적**, **상대와의 관계**, **원하는 인상**, **문장 끝의 톤**을 고르고 자연스러운 문장으로 이어 가게 만드는 두 번째 경험이다.

사용자는 “이 문장이 문법적으로 맞는가?”보다 “카페 직원·친구·팀장에게 이 말이 괜찮은가?”를 알고 싶어 한다. 한국어 학습자 31명과 원어민 12명의 요청 화행을 비교한 2024년 연구도, 기초 언어 요소를 습득한 학습자가 미묘한 사회적 맥락에서 이를 효과적으로 적용하는 데 어려움을 겪으며 문법 형태의 화용 기능을 명시적으로 가르칠 필요가 있다고 보고한다.[1]

> “Despite acquiring basic linguistic elements, KFL learners struggle to apply them effectively, particularly in nuanced social contexts.” — Kim & Yoon (2024) [1]

이 문제는 현재 SokDak이 이미 갖고 있는 신조어 검색, 모국어 의미, 로마자 검색, TTS, 저장, 실제 상황 표현 카드, 영상 슬롯과 정확히 이어진다. 앱은 이제 단어 상세 다음에 사용자를 멈추게 하는 대신 **“이 단어를 넣어 어떤 문장을 만들고 싶나요?”**라는 다음 행동을 제공해야 한다.

## 차별화된 제품 약속

> **“오늘 들은 한국 신조어, 뜻만 알지 말고 언제 어떻게 쓰는지 확인하세요.”**

| 기존 신조어 정보 탐색의 문제 | SokDak의 신조어 중심 흐름 |
| --- | --- |
| 뜻과 번역이 SNS·영상·댓글에 흩어져 있다 | 검색 가능한 한 곳에서 뜻·발음·유래·사용 장면을 확인한다 |
| 직역만 있어 실제 사용이 불안하다 | 관계·격식·민감도와 “써도 됨/주의/피해야 함”을 함께 본다 |
| 예문을 읽고 끝난다 | 찾은 신조어를 넣어 1개의 안전한 문장을 골라 본다 |
| 영상은 별도의 강의다 | 선택한 신조어가 실제 장면에서 어떤 톤으로 쓰이는지 본다 |
| 저장한 단어가 다시 흩어진다 | 저장 단어를 표현·문장·발음 중심으로 다시 꺼낸다 |

이 약속은 “AI가 문장을 만들어 준다”가 아니다. 첫 버전의 핵심은 자동 생성보다 **편집된 문장 선택**이다. 사용자가 완전히 자유로운 입력창에 문장을 던지고 불확실한 결과를 받기보다, SokDak이 검증한 자연스러운 선택지를 관계·장소·목적별로 좁혀 준다. 이렇게 하면 초급자도 실패 경험 없이 시작하고, 콘텐츠의 안전성과 번역 품질도 통제할 수 있다.

## 고유한 보조 경험: 문장 나침반

문장 코치의 제품명은 가칭 **문장 나침반**으로 둔다. 사용자는 신조어 상세 또는 저장한 단어에서 출발해 한국어 규칙을 먼저 암기하지 않고, 20~40초 안에 그 표현을 넣은 목적 맞춤 문장을 완성한다. 홈에서는 보조 카드로 노출되지만, 앱의 최상단 목적은 계속 신조어 검색과 발견이다.

### 1. 말할 일부터 시작한다

신조어 상세의 주 CTA는 “이 표현으로 문장 만들기”다. 사용자는 찾은 단어를 유지한 채 **친구에게 말하기**, **온라인에 쓰기**, **회사에서 쓰기**, **답장하기** 같은 목적 칩을 누른다. 문장 나침반은 번역 화면이 아니라, 이미 찾은 표현을 실제로 쓸 수 있게 하는 다음 단계다.

### 2. 관계·상황을 먼저 고른다

이후 화면은 “누구에게 말하나요?”를 묻는다. 친구, 처음 보는 사람, 카페 직원, 선생님·상사, 온라인 댓글, 단체 채팅처럼 사용자가 바로 이해하는 선택지와 짧은 시각 힌트를 제공한다. 높임말 교육 영상 분석에서도 높임의 대상과 대화 관계를 먼저 판단하는 것이 필요하며, 선택 알고리즘을 시각화하면 초급자의 판단 부담을 낮출 수 있다고 제안한다.[2]

> “누구와 누구의 대화인지”를 먼저 파악해야 높임말 선택이 가능하다. — 초급 높임말 수업 분석 [2]

### 3. 문장 블록으로 완성한다

사용자는 추상적 문법 강의를 보지 않고, `말하고 싶은 핵심 → 공손함 → 문장 끝`의 세 블록을 순서대로 선택한다. 예를 들어 카페에서 주문할 때는 “이거” → “하나” → “주세요”가 한 화면에서 쌓이고, “이거 주세요”와 “이거 하나 주세요”의 뉘앙스 차이를 짧게 설명한다. 직장에서 “검토 후 답장하겠습니다”를 만들 때는 “확인” → “후” → “회신드리겠습니다”로 조립되며, 친구에게 쓸 수 있는 “보고 연락할게”도 나란히 보여 준다.

| 실제 목표 | 관계·상황 | 안전한 문장 | 더 가벼운 대안 | 보여 줄 이유 |
| --- | --- | --- | --- | --- |
| 먼저 퇴근한다고 말하기 | 팀장·동료가 있는 사무실 | **먼저 퇴근하겠습니다.** | 먼저 들어갈게요. | 공적 자리에서는 격식 있는 종결을 우선 제안 |
| 카페에서 주문하기 | 직원 | **이거 하나 주세요.** | 이거 주세요. | “하나”가 수량·주문 의도를 부드럽게 분명히 함 |
| 약속 시간 묻기 | 친한 친구 | **언제 시간 돼?** | 이번 주에 시간 있어? | 직역보다 실제 대화에서 자주 쓰는 형태 제시 |
| 확인 후 답장하기 | 상사·고객 | **확인 후 회신드리겠습니다.** | 확인하고 연락드릴게요. | 업무 관계에서는 겸양·공손 표현을 명시 |

문장은 한 번에 완성되지 않는다. 사용자가 블록을 고르면 SokDak은 **“이 선택이 자연스러운 이유”**, **“이 상대에게는 피할 표현”**, **“더 따뜻하게·더 간단하게 말하는 방법”**을 한 화면에 보여 준다. 문법 설명은 “-세요는 공손합니다” 같은 일반론이 아니라 “직원에게 주문할 때는 `주세요`가 짧고 자연스럽습니다”처럼 행동과 연결한다.

### 4. 들리고, 보이고, 다시 쓴다

완성 뒤에는 TTS와 프리미엄 장면 영상이 연결된다. 영상은 단순 재생이 아니라 동일한 문장을 **자연스럽게 쓰는 장면**, **어색하거나 지나치게 직설적인 장면**, **안전한 대체 문장**의 세 컷으로 편집한다. 학습자는 “맞는 문장”이 아니라 “왜 이 장면에서 이 문장을 고르는가”를 듣고 본다.

> 초급자는 어간·높임 기저형·시제·종결 어미를 한 번에 처리하기보다 단계별 문장 생성과 반복 연습이 필요하다. — 초급 높임말 수업 분석 [2]

영상 다음에는 “내가 이 상황이면 어떤 문장을 고를까?”라는 1문항 선택 연습을 둔다. 틀린 답에도 점수나 벌점보다 “친구에게는 괜찮지만, 상사에게는 이 버전이 더 안전해요”를 안내한다. 사용자가 만든 문장은 자동으로 **내가 실제로 말하고 싶은 문장** 목록에 저장되어 1일·3일·7일 뒤 상황 카드로 다시 나타난다.

## 핵심 기능 우선순위

### P0 — 신조어 연결 문장 경로

첫 구현은 생성형 AI나 자유 작문 채점이 아니라 **상위 신조어에 연결된 편집형 문장 경로**다. `sentence_scenarios`, `sentence_intents`, `sentence_variants`, `sentence_slots`, `sentence_explanations` 데이터 모델을 추가하고 각 경로를 `word_id`에 연결한다. 각 경로는 목표, 관계, 장소·채널, 격식, 한국어 문장, 로마자, 6개 언어 설명, TTS, 사용 주의, 대체 표현, 영상 연결을 가진다.

처음에는 검색·저장·공유가 많은 신조어 40개에만 연결한다. 각 단어마다 친구·온라인·직장처럼 실제 사용 위험이 다른 2~3개 상황을 만들고, 상황당 2개의 톤을 제공한다. 이 방식은 문장 콘텐츠가 신조어 사전의 깊이를 높이되 독립적인 범용 회화 코스로 팽창하지 않게 한다.

### P1 — 문장 변환 렌즈

사용자가 이미 알고 있는 단어 또는 SokDak 사전에서 찾은 신조어를 문장 경로에 넣는다. 예를 들어 `찐`을 검색한 뒤 “친구에게 정말 좋다고 말하기”를 선택하면 “이거 진짜 찐이야”와 “이거 정말 좋아요”를 관계별로 비교한다. 이 기능이 사전·신조어·문장 코치를 하나의 경험으로 묶는다.

### P2 — 제한된 자유 입력 피드백

충분한 편집 데이터와 서버 보호가 준비된 뒤에만 사용자의 초안을 받는다. 이 단계도 단순 “번역 결과”가 아니라 `더 자연스러운 버전`, `더 공손한 버전`, `이 관계에서는 피할 이유`를 검증된 문장 경로에 근거해 제안한다. 생성 모델을 쓴다면 서버에서만 호출하고, 개인정보 최소화·악용 필터·잘못된 자신감 방지·사람 검수 가능한 피드백 데이터 구조를 갖춘다. 문장 코치의 핵심 가치는 AI의 문장 생성량이 아니라 **한국 생활의 정확한 판단**이다.

## 유료 가치 설계

문장 코치는 신조어 사전을 보조하는 유료 가치에 적합하지만, 첫 출시에서 독립적인 결제 이유로 앞세우지 않는다. 무료 사용자가 신조어의 뜻·기본 사용법·첫 문장 예시를 충분히 경험한 다음, 더 세밀한 자연스러움과 반복 학습에 비용을 지불하게 해야 한다.

| 무료: SokDak Free | 유료: SokDak Context | 유료로 느껴지는 이유 |
| --- | --- | --- |
| 검색 가능한 모든 신조어의 기본 뜻·예문·첫 사용 경로, 기본 TTS·저장 | 저장한 신조어의 무제한 문장 경로·관계별 변형·무제한 저장·TTS·개인 복습 | 한 번의 번역이 아니라 신조어를 반복적으로 안전하게 쓰는 개인 도구 |
| 짧은 사용 이유·1개 대안 | 주의 표현, 부드러운 변형, 실제 영상 3컷, 관계별 비교 | “뜻을 안다”를 넘어 “자연스럽고 안전하게 쓴다”를 얻음 |
| 무료 프리뷰 영상 | 전체 프리미엄 상황 영상·영상 기반 선택 연습 | 실제 장면에서 선택을 검증 |
| 로그인 기반 커뮤니티 | 저장 문장과 연동된 개인 복습·테마 큐 | 커뮤니티 접근권을 판매하지 않고 학습 효율을 판매 |

전환 순간은 사용자가 첫 자연스러운 문장을 완성한 뒤여야 한다. 예를 들어 “친구에게 말할 문장은 만들었어요. **팀장에게 말하는 더 안전한 버전도 확인할까요?**”라는 흐름이 적합하다. 여기서 유료는 문장을 감추는 잠금이 아니라, 사용자가 이미 느낀 가치를 더 깊게 하는 선택이 된다.

> Apple은 freemium과 미터드 페이월에서 사용자가 콘텐츠를 먼저 경험하고, 관련 맥락에서 구독을 제안하라고 안내한다. [3]

기존 제안인 Context 월 ₩4,900·연 ₩39,000·7일 체험은 문장 코치와 영상이 포함될 때 더 설득력이 생긴다. 가격은 가설이며, 비공개 베타에서는 결제를 켜지 않고 “무엇을 만들고 싶은가”, “관계별 대안을 어디까지 보려 하는가”, “영상이 결정을 바꾸는가”를 확인한 뒤 실험한다.

## 영상과의 결합

프리미엄 영상은 문장 코치의 **증거 장치**여야 한다. 단순 강의, 긴 문법 설명, 제3자 YouTube 링크는 결제 이유가 되기 어렵다. 직접 제작·라이선스 확보 영상만 사용해 20~60초 안에 다음을 보여 준다.

| 컷 | 역할 | 예시 |
| --- | --- | --- |
| 첫 장면 | 사용자의 실제 목표 | 카페에서 메뉴를 가리키며 주문함 |
| 대비 장면 | 관계·톤에 따른 차이 | 친구에게 쓰는 짧은 말과 직원에게 쓰는 주문 비교 |
| 선택 장면 | 안전한 최종 문장과 대체 표현 | “이거 하나 주세요”와 상황별 이유 |

YouTube 클립은 무료 참고 링크로만 유지한다. YouTube API 정책은 임베드 플레이어 시청에 요금을 청구하거나 접근을 제한하는 것을 금지하고, 이용약관도 권한 없이 콘텐츠를 판매·변경·이용하는 것을 제한한다.[4] [5] 프리미엄 영상은 private Storage·서버 entitlement 확인·짧은 signed URL·권리 메타데이터를 전제로 한다.

## 홈과 사전의 구체적 개편

현재 홈에는 “오늘의 실전 표현”과 상황별 표현 카드가 이미 있다. 이 영역은 신조어 검색·발견 다음의 보조 진입점으로 유지하며, 홈의 최우선 CTA와 탐색 구조는 신조어 검색으로 고정한다.

| 현재 요소 | 문장 코치 개편 | UX 효과 |
| --- | --- | --- |
| 검색·오늘의 신조어 영역 | **“오늘 들은 신조어를 찾아보세요”** + 로마자·모국어·음성 검색 | 흩어진 신조어를 찾는 핵심 과업으로 시작 |
| “오늘의 실전 표현” 카드 | 선택된 신조어의 “이 표현으로 문장 만들기” 보조 CTA | 발견한 표현을 실제 사용으로 연결 |
| 표현 1개와 영어 뜻 | 관계 선택 → 문장 블록 → 자연스러운 결과 | 초급자가 바로 산출 |
| 프리미엄 배너 | 문장 완성 뒤의 “더 공손하게/더 자연스럽게 말하기” 제안 | 가치 경험 후 전환 |
| 단어 상세의 영상 슬롯 | “이 단어로 문장 만들기” CTA와 장면 영상 | 사전 탐색을 실제 사용으로 연결 |
| 저장 목록 | “이번 주 실제로 말할 문장” 복습 큐 | 저장을 의미 있는 반복으로 전환 |

홈의 첫 문구는 다음처럼 신조어 발견과 안전한 사용을 직접 약속한다.

> **오늘 들은 한국 신조어, 여기서 찾아보세요.**
> 뜻부터 실제 사용법, 상대에게 맞는 한 문장까지 확인하세요.

## 성공 측정과 베타 검증

| 단계 | 주요 이벤트 | 성공 판단 |
| --- | --- | --- |
| 발견 | `word_searched`, `word_opened`, `word_usage_viewed` | 사용자가 흩어진 신조어를 빠르게 찾고 사용법을 이해하는가 |
| 의도 선택 | `sentence_intent_selected` | 찾은 신조어에서 문장 경로로 이어지는가 |
| 완성 | `sentence_completed`, `tone_variant_viewed` | 한 경로에서 최소 한 번 관계별 변형을 비교하는가 |
| 학습 | `sentence_saved`, `sentence_replayed`, `sentence_review_completed` | 만든 문장이 다시 사용되는가 |
| 영상 | `sentence_video_preview_completed`, `sentence_video_completed` | 영상이 문장 선택을 돕는가 |
| 전환 | `sentence_paywall_viewed`, `sentence_trial_started` | 성공 직후 맥락형 제안이 체험으로 이어지는가 |
| 안전 | `sentence_reported`, `sensitive_gate_shown` | 민감 상황의 편집·연령·신고 흐름이 작동하는가 |

비공개 베타에서는 10명 이상의 실제 거주 외국인에게 각각 카페·직장·친구 상황을 제시한다. 사용자가 60초 안에 문장을 만들고, 그 이유를 자신의 말로 설명할 수 있는지 본다. 결제 의향은 “이 기능에 돈을 낼래요?”가 아니라 “다음 주에도 이 상황에서 다시 열어 볼까요?”, “어떤 관계별 대안까지 보고 싶나요?”로 묻는다. 결제는 `BETA_UNLIMITED_ENTITLEMENTS`가 유지되는 동안 활성화하지 않는다.

## 최종 권고

SokDak이 사용자를 결제하게 만드는 첫 이유는 “이 앱에는 다른 곳에 흩어진 신조어가 잘 모여 있고, 뜻뿐 아니라 실제 사용법을 믿고 확인할 수 있다”는 경험이다. 그 다음 이유는 초급자도 찾은 신조어를 넣어 상대에게 맞는 자연스러운 문장을 만들고, 실제 장면에서 확인하고, 다음에도 다시 꺼내 쓸 수 있기 때문이다.

**신조어 탐색·사용 안내**를 SokDak의 핵심 경험으로 삼고, 문장 나침반·영상·저장·커뮤니티는 모두 이 경험을 깊게 만드는 구성으로 배치한다. 무료 사용자는 첫 신조어 검색과 안전한 사용 판단을 충분히 경험해야 하며, 유료 사용자는 관계별 판단·무제한 반복·프리미엄 장면 영상으로 “이 앱이 내 한국 생활을 실제로 편하게 만든다”는 이유를 얻어야 한다.

## 분석 공개

본 문서는 현재 SokDak의 검색·저장·TTS·상황 표현·영상 슬롯 구조와 2026-08-22 기준 연구·교육자 영상·스토어 구독 가이드를 바탕으로 작성했다. 문장 수, 무료 한도, 가격은 시장 사실이 아니라 베타에서 검증할 제품 가설이다. 민감 표현·결제·영상 권리는 정식 출시 전 별도의 권리·법률·스토어 정책 검토가 필요하다. 본 문서는 제품·UX·수익화 설계이며 법률 또는 세무 자문이 아니다.
