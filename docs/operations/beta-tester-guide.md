# SokDak 비공개 베타 테스터 안내

SokDak 비공개 베타에 참여해 주셔서 감사합니다. 이 버전은 무료 테스트 목적이며, 유료 결제나 구독 기능은 제공하지 않습니다. 앱과 커뮤니티 콘텐츠, 초대 링크, 테스트 중 발견한 오류를 공개적으로 공유하지 말아 주세요.

## 시작 전

초대 이메일 또는 초대 링크로 앱을 설치한 뒤, 사용 중인 기기와 운영체제 버전, 설치한 빌드 번호를 기록합니다. 베타 참여를 중단하려면 iOS는 TestFlight에서, Android는 Google Play 비공개 테스트의 opt-out 절차에서 언제든 탈퇴할 수 있습니다.

## 필수 검증 흐름

| 우선순위 | 흐름 | 통과 기준 |
|---|---|---|
| P0 | 회원가입·로그인·로그아웃 | 계정 전환과 세션 복원이 정상 동작 |
| P0 | 사전 검색·단어 저장 | 검색 결과와 저장 상태가 일관됨 |
| P0 | 게시글·댓글·답글 작성 | 운영정책 동의 후 작성되고 내용이 정상 표시됨 |
| P0 | 신고·차단 | 신고 접수와 차단 후 목록 필터링이 정상 동작 |
| P0 | 이미지 첨부 | JPEG·PNG·WebP, 5MB 이하 이미지가 업로드되고 큰 파일은 차단됨 |
| P0 | 계정 삭제 | 테스트 전용 계정으로만 실행하며, 삭제 뒤 재로그인 불가·콘텐츠 정리를 확인 |
| P1 | 알림 설정·고객지원 | 설정 저장 및 지원 티켓·답변 확인이 정상 동작 |

계정 삭제는 되돌릴 수 없으므로 실제 주계정이 아닌 테스트 전용 계정에서만 확인합니다. 오류를 보고할 때는 오류가 발생한 시각, 기기·OS·앱 빌드, 재현 단계, 기대 결과와 실제 결과를 함께 남기고 개인정보·비밀번호·토큰은 입력하지 않습니다.

## 피드백 채널

로그인 상태에서는 앱 내 고객지원 티켓을 우선 사용합니다. 긴급한 개인정보 노출·계정 접근 이상·유해 콘텐츠는 일반 피드백과 구분해 즉시 운영 담당자에게 알려야 합니다. 운영팀은 일반 피드백을 영업일 기준 24시간 안에 1차 확인하고, 긴급 안전 이슈는 즉시 검토합니다.
