# SokDak 비공개 베타 실기기 QA 체크리스트

**대상:** Android 우선 비공개 베타, 이후 iOS 공통 코드 검증
**목적:** 실제 기기에서 핵심 학습 흐름, 다국어 UI, 음성 검색, private 미디어, 인증 세션, 커뮤니티와 오류 복구가 기대대로 작동하는지 확인한다. 이 문서는 테스트 결과를 수집하기 위한 운영 체크리스트이며, 법률·스토어 심사 판정 문서는 아니다.

## 1. 테스트 시작 전 기록

각 테스터는 아래 정보를 먼저 기록한다. 이 정보가 없으면 기기·OS·네트워크 조건에 따른 결함을 재현하기 어렵다.

| 항목 | 기록할 값 |
| --- | --- |
| 테스트 일시·테스터 식별자 | 개인 실명 대신 내부 별칭 사용 |
| 앱 버전·빌드 번호 | 예: `1.0.0-beta.1 (build 12)` |
| 플랫폼·기기 | 예: Android / Pixel 8, iOS / iPhone 14 |
| OS·제조사 UI 버전 | 예: Android 15 / One UI, iOS 18 |
| 앱 표시 언어 | 한국어, 영어, 일본어, 베트남어, 스페인어, 독일어 |
| 네트워크 조건 | Wi-Fi, LTE/5G, 오프라인, 약한 연결 |
| 계정 상태 | 비로그인, 신규 테스트 계정, 기존 테스트 계정 |

> **데이터 원칙:** 실제 개인 이메일·전화번호·얼굴 사진·민감한 게시글을 기록하거나 결함 화면에 포함하지 않는다. 회원탈퇴와 프로필 사진은 반드시 전용 테스트 계정과 테스트 이미지만 사용한다.

## 2. 권장 기기·조건 매트릭스

Android 우선 검증에서는 제조사 UI와 뒤로가기 동작 차이를 확인한다. iOS는 실제 배포 전에 최소한 하나의 iPhone에서 권한·SecureStore·VoiceOver 동작을 확인한다.

| 우선순위 | 권장 조건 | 반드시 확인할 위험 |
| --- | --- | --- |
| P0 | Android 최신 OS의 Pixel 또는 동급 기기 | 음성 인식 권한, Android 시스템 뒤로가기, 마이크 복구 |
| P0 | Samsung Galaxy 또는 One UI 기기 | 권한 대화상자, 화면 비율·글자 크기, 제조사 UI 차이 |
| P1 | 저장 공간·메모리가 제한된 Android 기기 | 시작 속도, 이미지·목록 스크롤, 백그라운드 복귀 |
| P1 | 최신 iOS iPhone | 마이크·음성 인식 권한, SecureStore 세션, VoiceOver |
| P2 | 작은 화면 iPhone 또는 Android 기기 | 6개 언어 줄바꿈, CTA 폭, 키보드·하단 탭 가림 |
| P2 | Wi-Fi ↔ LTE/5G 전환 및 오프라인 | 오류 복구, 재시도, 저장 데이터 손실 여부 |

## 10. 비공개 베타 종료 기준

Android 우선 베타의 최소 통과 기준은 **미해결 P0가 0건**이고, Android 대표 기기에서 로그인·검색·음성 검색·저장·커뮤니티·오류 복구·회원탈퇴 흐름을 재현 가능하게 통과한 상태다. iOS 공개 전에 iPhone에서 동일한 핵심 흐름과 마이크·음성 인식·세션 저장·VoiceOver를 별도로 재검증한다.

테스트 종료 보고에는 기기·OS별 통과율, 미해결 P1/P2 목록, 보류 사유, 재검증한 빌드 번호, 그리고 티콘파이 캐릭터 권리·정책 전문·운영 모니터링처럼 코드만으로 닫을 수 없는 출시 의존 항목을 함께 남긴다.
