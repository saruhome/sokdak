서버가 최신 동의만 인정합니다

클라이언트의 조작을 원천 차단하고, 전용 RPC와 DB 트리거를 통해 권한을 엄격하게 통제합니다.

05

RPC 기반 동의 및 검증

accept_current_community_policy

로그인 상태, 요청 언어, 활성 번역본을 서버에서 직접 검증합니다. 검증 통과 시 동의 원장과 UI 캐시를 단일 트랜잭션으로 갱신하여 데이터 정합성을 보장합니다.

has_accepted_current_community_policy

클라이언트가 화면 게이트(UI) 상태를 판정할 때 사용하는 읽기 전용 RPC입니다. 단순 캐시가 아닌 실제 원장 기반의 최신 상태를 반환합니다.

DB 트리거 최종 강제

posts & comments INSERT Trigger

사용자가 게시글이나 댓글을 작성하는 순간, 데이터베이스 레벨에서 개입합니다. 최신 활성 정책에 대한 동의 이력이 원장에 존재하는지 최종적으로 확인합니다.

클라이언트 앱이 변조되거나 API를 직접 호출하는 우회 시도가 발생하더라도, DB 트리거가 쓰기 작업을 원천 차단하여 커뮤니티의 안전을 지킵니다.
