# SokDak 영상 유료화 전략

**작성:** Manus AI

**기준일:** 2026-08-22

**범위:** 한국 거주 외국인을 위한 다국어 신조어 학습 앱 SokDak의 유료 영상 콘텐츠 설계

## 결론

SokDak의 영상은 유료화할 수 있다. 다만 유료화 대상은 **SokDak이 직접 제작했거나, 앱 내 유료 스트리밍·편집·번역·지역·기간 사용권을 서면으로 확보한 영상**에 한정해야 한다. 현재 단어 데이터가 지원하는 제3자 YouTube 클립은 무료 참고 링크로만 남기고, 구독·단품 구매·저장 제한의 대가로 잠그면 안 된다.

> YouTube API Client는 “embedded YouTube player에서 콘텐츠 시청을 위해 사용자에게 요금을 청구하거나, 영상 접근을 다른 방식으로 제한해서는 안 된다.” — YouTube API Services Developer Policies [1]

YouTube 이용약관도 YouTube 또는 권리자의 사전 서면 허가 없이는 콘텐츠를 판매·라이선스·변경하거나 서비스 밖에서 이용할 수 없다고 정한다.[2] 따라서 YouTube 영상 자체나 그 영상의 하이라이트 재생 접근을 SokDak Premium에 넣는 방식은 채택하지 않는다. 반면, SokDak이 직접 만든 20~60초의 미니 레슨 영상과 권리를 확보한 진행자·배우 영상은 **SokDak Context 구독의 반복 가치**로 포함하는 것이 적합하다.

## 현재 구현 상태와 판단

현재 `WordVideo`는 세 가지 경로를 지원한다. `videoUrl`은 직접 보유 또는 라이선스한 MP4·스트리밍 URL을 인앱에서 재생하고, `youtubeId`는 웹 임베드 또는 네이티브 YouTube 이동으로 재생하며, `thumbnailUrl`은 정지 이미지를 표시한다. `words` 데이터에는 영상 URL·YouTube ID·시작·종료 시점·썸네일 필드가 이미 있다. 즉, UI 슬롯은 준비돼 있지만 **권리 메타데이터, 유료 접근 등급, 서버 기반 entitlement 확인, 영상 전용 private Storage 정책은 아직 없다.**

| 콘텐츠 출처 | Premium 포함 가능 여부 | 필요한 조건 | SokDak 운영 원칙 |
| --- | --- | --- | --- |
| SokDak 직접 제작 영상 | 가능 | 출연자·음성·음악·이미지의 제작 권리 정리 | 첫 번째 Premium 영상 라이브러리의 기본 |
| 외주·크리에이터 제작 영상 | 가능 | 유료 스트리밍, 편집, 번역·자막, 광고, 스토어 배포, 지역·기간 범위를 포함한 서면 계약 | 계약서·이용 범위를 `media_assets`에 기록 |
| 스톡 영상·음원 | 조건부 가능 | 상업적 앱 내 유료 스트리밍 및 편집·재배포가 허용되는 라이선스 | 라이선스 증빙과 만료일 없이는 발행 금지 |
| 제3자 YouTube 클립 | **유료 잠금 불가** | YouTube 공식 플레이어를 통한 무료 참고 접근 또는 별도 권리자 계약 | 무료 참고 링크로만 사용; 해당 영상의 프리미엄 접근 불가 |
| 드라마·예능·K-pop·영화 장면 | 계약 전 불가 | 영상·음원·대사·자막·2차적 이용의 명시적 라이선스 | “교육 목적”만으로 사용하지 않음 |
| 사용자 업로드 영상 | 초기에는 비권장 | UGC 정책, 신고·차단·권리 보증·모더레이션·동의·연령 관리 | 유료 콘텐츠 공급원으로 사용하지 않음 |

## 권장 상품 구조

첫 정식 출시에서는 새 비디오 전용 요금제를 만들지 않는다. 기존 권장안인 **SokDak Context 월 ₩4,900 / 연 ₩39,000 가설**에 “프리미엄 미니 레슨 영상”을 포함한다. 구독자가 영상뿐 아니라 무제한 저장·무제한 카테고리·TTS·관계별 사용 주의·자연스러운 대체 표현·개인 복습 큐를 함께 받도록 해야 갱신 가능한 가치가 된다.

Apple은 반복적으로 업데이트되거나 콘텐츠 라이브러리에 접근하는 앱에서 자동 갱신 구독을 허용하며, 반복 가치를 정기적으로 제공할 것을 안내한다.[3] Google Play도 교육·영상·기능성 디지털 콘텐츠 구독을 Play Billing 대상이라고 명시한다.[4] 따라서 영상은 별도 “영화 대여”가 아니라 Context의 **상황형 학습 모듈**로 묶는 것이 제품·결제·메시지 측면에서 단순하다.

| 계층 | 무료 사용자 경험 | SokDak Context 경험 | 전환 논리 |
| --- | --- | --- | --- |
| 표현 카드 | 전체 표제어·짧은 뜻·짧은 예문 | 관계·장소·톤별 심화 설명 | 단어 자체는 숨기지 않음 |
| 영상 | 5~12초의 무음 또는 저자극 프리뷰, 영상의 학습 목표·자막 한 줄 | 20~60초의 전체 상황 연기, 다국어 자막, 반복 재생, ‘피해야 할 경우’와 대체 표현 | ‘재생’이 아니라 실제 사용 판단을 제공 |
| 학습 흐름 | 제한된 저장·TTS·카테고리 | 무제한 저장·TTS·카테고리, 영상 기반 복습 큐 | 반복 학습 효율을 판매 |
| 커뮤니티 | 로그인 사용자 모두 이용 | 저장 영상 표현을 주제로 한 개인 복습 제안 | 커뮤니티 읽기·안전 기능은 유료화하지 않음 |

첫 영상 묶음은 6~10개 표현만으로 시작하지 않는다. 최소 **12개의 주제 카드와 36개 이상의 편집된 미니 영상**이 있어야 “이번 주 새 영상”이라는 구독 약속을 지킬 수 있다. 카드 하나당 같은 표현을 세 방식으로 구성한다. 첫째, 실제로 써도 되는 상황, 둘째, 오해되거나 무례해지는 상황, 셋째, 안전한 대체 표현을 보여 준다. 예를 들어 “찐이다”는 친구의 취향 대화, 직장 상사 앞에서의 부적절한 사용, “정말 좋아요”라는 대체 표현을 한 묶음으로 제공한다.

## 판매 메시지와 페이월

영상은 “프리미엄 영상 잠금 해제”가 아니라 **“실제 장면에서 듣고, 말하고, 피할 표현까지 확인하기”**로 판매한다. 신조어를 실사·맥락으로 보여 주면 외국인 사용자는 번역이 맞더라도 상황이 틀릴 수 있다는 문제를 더 빨리 이해한다. 무료 프리뷰는 전환을 돕되, 무료 사용자도 학습 가치가 남아야 한다.

| 페이월 트리거 | 문구 예시 | 보여 줄 근거 | 빈도 제한 |
| --- | --- | --- | --- |
| 영상 프리뷰 종료 | “이 표현, 친구에게는 괜찮지만 상사에게는 달라요.” | 실제 장면·대체 표현·다국어 자막 | 같은 단어에서 하루 1회 |
| 같은 단어 2회 검색 | “다음 대화 전에 40초 상황 영상을 확인하세요.” | 전체 장면·사용 주의 라벨 | 세션당 1회 |
| 저장 한도 도달 | “자주 들은 표현을 영상과 함께 다시 연습하세요.” | 무제한 저장·영상 복습 큐 | 한도 도달 뒤에만 |
| 주간 테마 진입 | “이번 주: 회사 단톡방에서 자주 듣는 말” | 3개 무료 프리뷰 + 전체 12개 모듈 | 주간 테마별 1회 |

무료 프리뷰에는 노골적·성인·모욕적 장면을 넣지 않는다. 민감 표현은 기본 숨김·선언 연령 게이트·비노골적 교육 맥락을 전제로 하며, 프리미엄 전환의 주된 미끼로 사용하지 않는다. 이는 Apple의 성적·UGC 안전 규칙과 Google Play의 부적절 콘텐츠 정책에 맞추는 동시에 SokDak의 신뢰 브랜드를 보호한다.[5] [6]

## 필수 데이터·접근 제어 구조

현재 단어 테이블의 `video_url`만으로는 유료 보호가 불가능하다. 앱이 URL을 받으면 클라이언트에서 공유·복제할 수 있고, 비공개 베타용 `BETA_UNLIMITED_ENTITLEMENTS`는 정식 출시에서 서버 권한 판정으로 대체돼야 한다. 다음 구조를 권장한다.

| 구성 요소 | 권장 설계 | 금지 사항 |
| --- | --- | --- |
| `media_assets` 테이블 | `id`, `word_id`, `access_tier`, `storage_path`, `preview_path`, `source_type`, `rights_status`, `license_document_ref`, `territory`, `license_expires_at`, `captions`, `published_at`, `retired_at` | 권리 상태·만료일 없는 유료 게시 |
| Storage | `premium-word-videos` **private bucket**. 프리뷰와 전체 영상을 분리 | public URL을 DB에 저장하거나 앱 번들에 전체 MP4 포함 |
| 영상 URL 발급 | 로그인 토큰을 확인하는 Edge Function이 entitlement·권리 상태·만료일을 검사한 뒤 짧은 signed URL 발급 | 클라이언트가 `isPremium`을 직접 수정해 URL 발급 |
| entitlement | Google Play·App Store 영수증을 서버에서 검증하고, 웹훅으로 `is_premium`과 기간을 갱신 | 결제 직후 클라이언트 상태만 갱신하거나 앱 로컬 저장소를 권한 원본으로 사용 |
| 재생 | `video_access_requested`, `video_started`, `video_completed`, `preview_completed`를 최소 개인정보로 기록 | 영상 시청 여부로 개인 프로파일을 과도하게 만들기 |
| 권리 만료 | `license_expires_at` 전 사전 알림, 만료 시 프리미엄 노출·signed URL을 즉시 중단하고 대체 카드 제공 | 계약 만료 후 기존 캐시 URL을 방치 |

Google Play은 앱과 서버 백엔드를 함께 연동해 구매 검증, 구독 기능, 실시간 개발자 알림을 처리하는 구조를 권장한다.[7] Apple도 StoreKit과 App Store Server API·Server Notifications를 통한 구독 상태 갱신을 안내한다.[3] SokDak은 기존 `account_settings.is_premium`을 클라이언트에서 직접 쓰지 않도록 설계해 두었으므로, 이 원칙을 영상까지 확장하면 된다.

| 단계 | 실행 내용 | 출시 통과 기준 | 차단 기준 |
| --- | --- | --- | --- |
| 0. 권리 인벤토리 | 각 영상의 제작자, 출연자, 음원, 원본, 계약, 사용 지역·기간·편집·번역 권한을 기록 | 모든 Premium 후보가 `rights_status=cleared` | YouTube ID·캡처·드라마 장면만 있는 영상 |

| 2. 유료 접근 구현 | private Storage, Edge Function, 서버 영수증 검증, 구독 복원·취소·갱신 처리 | Android sandbox에서 구매·복원·만료·취소 뒤 URL 차단 확인 | 공개 URL·클라이언트 플래그만 사용하는 구현 |
| 3. 베타 검증 | 전환 문구, 프리뷰 길이, 재생 성공률, 자막 이해도, 신고 흐름 측정 | 재생 실패·권한 오류·권리 문서 누락 없이 통과 | 민감 표현의 연령·모더레이션 경로 미완성 |
| 4. Android 제한 출시 | Context 단일 구독에 영상 포함, 7일 체험 가설 검증 | 결제·영상·복원·지원 안내가 일치 | 여러 요금제·단품 팩을 동시에 시작 |

## 현재 결정

**영상 유료화는 채택한다.** 단, 첫 제품은 “SokDak Context에 포함된 자체 제작·라이선스 미니 레슨 영상”으로 제한한다. 현존 YouTube 클립은 무료 참고 링크로만 유지하며 유료 재생·유료 잠금·재호스팅을 하지 않는다. 영상 전용 단품 패키지는 첫 구독 상품의 전환·유지·권리 운영이 안정된 뒤에 검토한다.

비공개 베타 기간에는 결제를 활성화하지 않는다. 대신 권리 인벤토리 양식과 12개 카드·36개 클립의 최소 콘텐츠 기준을 마련하고, 사용자가 “영상 상황 설명”을 실제로 원하는지 인터뷰와 프리뷰 완료율로 확인한다. 사업자 등록, 스토어 상품 설정, 서버 영수증 검증, 서면 권리 확보가 완료되기 전에는 `BETA_UNLIMITED_ENTITLEMENTS`를 유지한다.

## 분석 공개

본 문서는 현재 코드의 영상 경로와 2026-08-22 기준의 YouTube·Apple·Google 공식 정책을 토대로 작성했다. 현재 영상의 실제 권리 계약, 제작 수량, 사용자 전환 데이터, 스토어 상품 설정은 확인되지 않았으므로 가격·콘텐츠 수·프리뷰 길이는 운영 가설이다. 각 영상의 상업 이용 권리와 계약 적합성은 정식 출시 전 전문가 검토 및 서면 증빙이 필요하다. 본 문서는 제품·운영 설계 문서이며 법률 자문이 아니다.
